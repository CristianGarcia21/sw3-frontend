# HU-04 · Asignarme un caso

**Como** agente, **quiero** asignarme un caso, **para** asumir su atención.

| Campo | Valor |
|---|---|
| Tipo de caso relacionado | Incidente y Solicitud de servicio |
| Área / Categoría | Todas |
| Prioridad | P1 |
| Story Points | 3 |
| Sprint | 2 |
| Dependencias | HU-03, HU-05 (la regla RN-11 se conecta con la máquina de estados) |

## Reglas de negocio
RN-11, RN-17, RN-18, RN-19.

1. Solo usuarios con rol Agente activos se pueden asignar.
2. Se puede asignar o reasignar solo en `Pendiente` o `En análisis`.
3. Al asignar se guarda el agente y `fecha_asignacion`, y se crea el evento `ASIGNACION` en el historial.
4. Si no hay agente asignado, el caso no puede pasar a `En atención`.

## Criterios de aceptación
- **Escenario 1: asignarme.** Given un caso `Pendiente` sin agente, When el agente pulsa "Asignarme", Then el caso muestra a ese agente como responsable, con fecha de asignación, y el historial registra el evento.
- **Escenario 2: reasignar.** Given un caso `En análisis` asignado a Andrés, When Marta se lo asigna, Then el responsable pasa a Marta y queda en el historial.
- **Escenario 3: caso ya en atención.** Given un caso `En atención`, When alguien intenta reasignarlo, Then el sistema lo rechaza.
- **Escenario 4: sin agente no hay atención.** Given un caso `En análisis` sin agente, When se intenta pasar a `En atención`, Then el sistema lo impide.
