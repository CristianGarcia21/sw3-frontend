# HU-08 · Consultar el historial

**Como** usuario autorizado, **quiero** consultar el historial de un caso, **para** saber qué pasó con él.

| Campo | Valor |
|---|---|
| Tipo de caso relacionado | Incidente y Solicitud de servicio |
| Área / Categoría | Todas |
| Prioridad | P2 |
| Story Points | 5 |
| Sprint | 2 |
| Dependencias | HU-05 (genera los eventos). Se va completando con HU-04, HU-06 y HU-07 |

## Reglas de negocio
RN-17.

1. Agentes, validadores y administradores ven el historial de cualquier caso. El solicitante solo el de sus casos.
2. Se muestra en orden cronológico: fecha, evento, estado anterior → estado nuevo, usuario y comentario.
3. El historial no se edita ni se borra.

## Criterios de aceptación
- **Escenario 1: flujo completo.** Given un caso que pasó por todo el flujo, When un agente abre su historial, Then ve un evento por cada paso con su usuario y fecha.
- **Escenario 2: devolución visible.** Given un caso devuelto, When se consulta el historial, Then aparece el comentario del validador.
- **Escenario 3: solicitante ajeno.** Given el caso de Laura, When Carlos pide su historial, Then el sistema responde 403.
