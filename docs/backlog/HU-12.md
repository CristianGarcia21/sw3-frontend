# HU-12 · Detalle de mi caso y solución

**Como** solicitante, **quiero** consultar el detalle de mi caso y la solución registrada, **para** saber qué se hizo.

| Campo | Valor |
|---|---|
| Tipo de caso relacionado | Incidente y Solicitud de servicio |
| Área / Categoría | Todas |
| Prioridad | P3 |
| Story Points | 3 |
| Sprint | 3 |
| Dependencias | HU-02, HU-06 |

## Reglas de negocio
RN-20.

1. El detalle muestra todos los datos del caso, el agente responsable, las fechas y la solución vigente (la atención más reciente).
2. Si todavía no hay solución se muestra "Aún sin solución registrada".
3. El solicitante solo puede abrir el detalle de sus propios casos.
4. Incluye el historial resumido del caso.

## Criterios de aceptación
- **Escenario 1: con solución.** Given un caso cerrado de Laura, When Laura abre el detalle, Then ve el diagnóstico, la solución, el agente y la fecha de cierre.
- **Escenario 2: sin solución.** Given un caso `Pendiente`, When abro el detalle, Then veo "Aún sin solución registrada".
- **Escenario 3: caso ajeno.** Given el caso de Laura, When Carlos intenta abrir su detalle, Then el sistema responde 403 y el front muestra un mensaje.
