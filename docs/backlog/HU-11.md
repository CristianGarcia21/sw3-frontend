# HU-11 · Gestionar categorías

**Como** administrador, **quiero** gestionar las categorías de soporte, **para** mantener la clasificación al día.

| Campo | Valor |
|---|---|
| Tipo de caso relacionado | Incidente y Solicitud de servicio |
| Área / Categoría | Todas |
| Prioridad | P2 |
| Story Points | 3 |
| Sprint | 3 |
| Dependencias | HU-01 (usa el modelo y el seed de categorías) |

## Reglas de negocio
RN-03, RN-21, RN-22.

1. El administrador puede crear, editar, activar/desactivar y borrar categorías.
2. Toda categoría pertenece a un área.
3. No se repite el nombre dentro de la misma área.
4. Una categoría con casos no se borra, solo se desactiva.
5. Las inactivas no salen en el formulario de registro.

## Criterios de aceptación
- **Escenario 1: crear.** Given el área Software, When creo la categoría "Licencias", Then aparece en el formulario de registro al elegir Software.
- **Escenario 2: duplicada.** Given ya existe "Wi-Fi" en Red y conectividad, When intento crear otra "Wi-Fi" en esa área, Then el sistema lo rechaza.
- **Escenario 3: desactivar.** Given la categoría "Proyector" activa, When la desactivo, Then ya no aparece al registrar, pero los casos viejos la siguen mostrando.
- **Escenario 4: borrar con casos.** Given una categoría usada por un caso, When intento borrarla, Then el sistema lo impide y sugiere desactivarla.
