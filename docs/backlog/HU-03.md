# HU-03 · Bandeja de casos del agente

**Como** agente, **quiero** ver la bandeja de casos pendientes, **para** seleccionar el trabajo que voy a atender.

| Campo | Valor |
|---|---|
| Tipo de caso relacionado | Incidente y Solicitud de servicio |
| Área / Categoría | Todas |
| Prioridad | P1 |
| Story Points | 3 |
| Sprint | 1 |
| Dependencias | HU-01 |

## Reglas de negocio
1. Por defecto la bandeja muestra los casos que no están `Cerrada`.
2. Se ordena primero por prioridad (P1, P2, P3) y luego por antigüedad (más viejo primero), para que lo urgente y lo que más espera quede arriba.
3. Cada fila muestra ID, título, tipo, área, categoría, prioridad, estado, solicitante, agente (o "Sin asignar") y hace cuánto se creó.
4. Hay una pestaña rápida "Pendientes" y otra "Asignados a mí".

## Criterios de aceptación
- **Escenario 1: ver pendientes.** Given existen casos en varios estados, When el agente abre la bandeja, Then ve los casos no cerrados ordenados por prioridad y antigüedad.
- **Escenario 2: caso nuevo.** Given un solicitante acaba de registrar un caso, When el agente recarga la bandeja, Then el caso aparece como `Pendiente` y "Sin asignar".
- **Escenario 3: ir al detalle.** Given la bandeja con casos, When el agente hace clic en uno, Then se abre el detalle del caso.
