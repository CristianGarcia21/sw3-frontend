# HU-09 · Filtrar casos

**Como** administrador, **quiero** filtrar los casos, **para** encontrarlos rápido.

| Campo | Valor |
|---|---|
| Tipo de caso relacionado | Incidente y Solicitud de servicio |
| Área / Categoría | Todas |
| Prioridad | P2 |
| Story Points | 3 |
| Sprint | 3 |
| Dependencias | HU-03 |

## Reglas de negocio
1. Filtros: estado, tipo, área, categoría y prioridad. Además búsqueda por texto en el título.
2. Los filtros se combinan (Y lógico).
3. La categoría disponible depende del área elegida.
4. Los filtros quedan en la URL para poder compartir o recargar la búsqueda.
5. Hay un botón para limpiar filtros.

## Criterios de aceptación
- **Escenario 1: un filtro.** Given casos de varias áreas, When filtro por área "Red y conectividad", Then solo aparecen casos de esa área.
- **Escenario 2: filtros combinados.** Given casos variados, When filtro por tipo Incidente y prioridad P1, Then solo aparecen incidentes P1.
- **Escenario 3: sin resultados.** Given ningún caso coincide, When aplico filtros, Then se muestra "No hay casos con esos filtros".
- **Escenario 4: limpiar.** Given filtros aplicados, When pulso "Limpiar", Then se ven todos los casos otra vez.
